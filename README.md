# API REST com Node.js, Express e TypeScript

A API trabalha com uma lista de usuários e permite consultar todos os registros ou buscar um usuário específico pelo nome. Durante o desenvolvimento, pratiquei a criação de rotas, a tipagem de dados com interfaces e o tratamento de respostas HTTP para situações em que um usuário não é encontrado.

## 🚀 Tecnologias utilizadas

- **Node.js** — ambiente de execução JavaScript.
- **Express** — criação e gerenciamento das rotas da API.
- **TypeScript** — tipagem estática para melhorar a organização e a segurança do código.

## ⚙️ Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/andrezinhodev/API-Rest-Node.Js-Express-e-TypeScript.git
   ```

2. Acesse a pasta do projeto e instale as dependências:

   ```bash
   npm install
   ```

3. Execute a API com o `tsx`, caso esteja instalado no projeto:

   ```bash
   npx tsx app.ts
   ```

4. Acesse `http://localhost:3000` no navegador para conferir a mensagem inicial da API.

## 🎯 Objetivo do projeto

Este é um projeto de estudo que faz parte da minha jornada de aprendizado em desenvolvimento back-end. A ideia é fortalecer minha base em Node.js, Express e TypeScript, entendendo como estruturar rotas, trabalhar com dados tipados e construir APIs de forma organizada.

Pretendo continuar evoluindo o projeto conforme avanço nos estudos, explorando novos recursos e boas práticas de desenvolvimento.
